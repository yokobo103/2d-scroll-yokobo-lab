# 1F 通常ラボ — Dr.よこぼ セリフ正本

更新日: 2026-08-15  
用途: `data/crystal-lab-scene-hooks.json` の装置近傍トリガーと、今後追加するラボ装置のセリフ原案。

## 書き方の規則

- Dr.よこぼは装置をよく知っているが、作者か長年の使用者かは確定しない。
- 作者・製作者だと断定する言い方は禁止。
- 操作説明は命令文ではなく、状況を見た独り言として書く。
- 1装置につき初回接近時の1回だけ表示する。
