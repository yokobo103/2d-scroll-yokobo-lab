## フロア設定

**設備としての役割**: 研究所の顔。日常的な実験と観測を行うメインエリア。

**暴走の症状**: 軽微。掃除ロボが止まらない、装置が勝手に動く程度。**ここはまだ正常に見える。**

**降り方**: **昇降リフト**。正規の設備が生きており、ボタンを押せば降りられる。

**止める対象**: ニャビクリーン（巡回）、ネジニャビ（周期ジャンプ）、ニャビドローン（レーザー）

### ギミック

| ギミック | 世界観との結び |
|---|---|
| **装置の起動スイッチ** | 研究所で働く行為がそのまま遊びになる。スイッチを押すと装置が動き、それが道になる。**この階の主役ギミック** |
| **昇降リフト** | 正規の移動手段。降り方の基準を教える |
| **動く床（実装済み）** | 搬送ライン。研究所の日常 |
| **結晶成長装置（実装済み）** | スイッチでシアン系の安定結晶が横・上へ徐々に成長し、見えている部分だけ足場になる |
| **紫の尖り結晶（実装済み）** | 不安定な析出結晶。床に接地し、紫の尖りと暗い輪郭で接触ダメージを示す |
| **ラボ装置（シルエット選定中）** | 本来の仕事を続ける装置が、壊れずに進行を妨げる。追加候補として選定待ち |

**環境色**: 白〜クリーム、ネイビー、シアン発光。明るく親しみやすい。

**結晶の色と意味**: 紫の尖った群晶は常設ダメージ。シアン〜水色の群晶は一時的に利用できる足場。白濁・亀裂・振動は崩壊予兆。紫を足場の劣化色に使わない。オレンジは機械装置の警告に限定する。

**設計意図**: この階だけは**安全であることを見せる階**である。難しくしない。プレイヤーに操作と世界を覚えさせ、「研究所は本来こういう場所」という基準を作る。下の4階はすべてこの基準からの逸脱として読まれる。

## 採用済みアセット

- `crystal-spikes-v1` — `LEFT / MID_A / MID_B / MID_C / RIGHT`で任意長に連結する、大中の柱が重なった紫のアメジスト群晶
- `crystal-growth-horizontal-v1` — 床ノズル直上の巨大な逆三角形コアから、薄い歩行プレートが左右へ伝播して一時足場になる
- `crystal-growth-vertical-v1` — 装置の結晶核から小群晶が上下へ連鎖し、成長先端と当たり判定が同期する

成長結晶は1枚絵の単純なscale伸長と、花束状の同型群晶を横一列に反復する構成を禁止する。横足場の完成形は、床埋め込みノズルへ接続した巨大な逆三角形コア、薄く平らで連続した歩行プレート、中央から両端へ小さくなる側面結晶を持つ一体型シルエットとする。旧仕様の浅い横長結晶ブロック／厚い均一スラブは不採用。成長中は中央から左右へのクリップとコリジョン幅を同期し、完成時にはノズル・コア・歩行面が一本の結晶構造に見えること。`direction / length / growthSpeed / activeDuration / collapseDuration / segmentSpacing`で構成し、核→歩行面の伝播→減光→白濁→亀裂→振動→透明破片の順で消滅する。

横足場のアニメーションは`inverted-core-growth-1..6`と`inverted-core-collapse-1..6`の専用スプライトを使う。生成は待機ノズル→核→中央コア→短い歩行面→左右拡張→完成、崩壊は完成→減光→白濁・亀裂→欠損→大破→残留破片の順。コード描画だけの白濁・亀裂オーバーレイへ戻さない。

横足場上面はノズル設置床から160px上とし、通常ジャンプの理論上昇量約166pxでぎりぎり直接到達可能にする。スプライトは透明キャンバス端ではなく実画素下端をノズル設置床へ、歩行面の実画素上端をコリジョン上面へ合わせる。細い縦結晶とその専用ノズルは1F実配置から撤去する。遠隔スイッチのWi-Fi表示は非接触の状態表示であり、起動判定は下部の装置本体だけに限定する。

## 採用の傾向

**2026-08-14 所長判断**

- 妨害装置は、**ラボのマシンが結果的に邪魔をしてくる**姿にする。装置は壊れているのではなく、**本来の仕事を続けている**
- Dr.よこぼは装置をよく知っているが、作者か長年の使用者かは作中で確定しない
- 説明はモノではなく**キャラクターの声**で行う
- 装置は研究所らしいMサイズの本体と、避ける対象であるSサイズの可動部へ分ける
- 1Fは安全な導入階なので、押し戻す・弾く・塞ぐなどダメージなしの妨害を多めにする

## このフロアで避けること

**2026-08-14 所長判断**

- **環境ハザードを主役の妨害装置にしない。**噴出口・液だまりのような「建物が壊れて漏れている」表現は、このフロアの主役にしない

**2026-08-15 所長判断 — 「出る危険」は1Fで作らない**

- **噴出・放電・噴霧のような「出る危険」を1Fに置かない。**成立させるには「配管があり、中を何かが流れ、その先に口がある」という絵が要る。現状の表現力では届かず、置くと文脈のない浮いた物体になる
- 配管・流れの表現は、**それ自体が階のテーマになる2F電気室・5Fコアで行う**
- **「溜まる危険」（液だまり）は当時は残してよいとした。**後の結晶テーマ統一により、1F実配置からは撤去した
- 危険の3分類: **動く危険**（単体で成立）/ **出る危険**（供給源が要る）/ **溜まる危険**（上流の事故で説明がつく）
- **看板・掲示で世界観を説明しない。**プレイヤーより大きい掲示物を置かない
- 噴出口候補と現行噴出口は1Fから外す。供給経路を描ける2F・5Fで再検討する
- 装置の本体全体を危険判定にしない。危険判定はSサイズの可動部外形と一致させる
- （参考: 却下時点の実測。区画案内 280×180、チュートリアル 260×180、注意標識 240×170。いずれもプレイヤー描画194を超えていた）

## 2026-08-15追加判断 — 結晶テーマ

- ハザードは紫の尖った結晶へ統一する。床との接地線を持たせ、背景用結晶と同じ大きさ・彩度にしない
- 足場結晶はシアン系、平らな上面、機械式の培養根を必須とし、紫のハザードと見分けられるようにする
- スイッチを押すと横または上へ徐々に成長し、コリジョンは見えている上面と同期させる
- 横成長は根元から先端まで見えている長さだけ歩ける。上成長は先端上面が上昇し、乗っているプレイヤーを運ぶ
- 成長は1枚画像のscaleではなく、0.08〜0.15秒間隔の独立セグメント析出で表現する。足場当たり判定も析出量へ同期する
- 成長後は「発光低下→白濁→亀裂→先端から崩壊」の順で消滅し、装置は再起動可能になる
- ハザード結晶は`LEFT / MID_A / MID_B / MID_C / RIGHT`の連結文法を持ち、任意長でも紫の尖った群晶として継ぎ目なく組む
- 結晶成長は床埋め込みノズル`crystal-growth-nozzle-v1`から噴出する。旧培養タンク型`crystal-culture-switch-v1`は不採用
- 起動は別置きの`crystal-remote-switch-v1`で行い、`activateTargetIds`により1台から複数ノズルを同時制御できる。肉球スイッチ`lab-switch-v1`はエレベーター専用
