# 接地素材の制作規格

このゲームでは、画像の外枠を接地基準にしません。キャラの靴底と足場の連続した床レールを測定し、ランタイム素材へ正規化してから使用します。

## キャラアクションを追加する

1. `generate2dsprite` でアクション単位の複数行グリッドを生成・処理する。
2. 全フレームを同じ320×320キャンバス、`align=feet`、`shared_scale=true` で出力する。
3. `assets/sprites/dr_yokobo/contact-source-spec.json` の `actions` に、処理済みフレームの場所・パターン・再生時間を登録する。
4. `npm run assets:normalize` を実行する。
5. `npm run validate:contact` が通ることを確認する。
6. ゲームは `assets/sprites/dr_yokobo/runtime/` のみ参照する。処理済み素材を直接参照しない。

地上で使うアクションは、靴底が複数ピクセル幅で明瞭に存在すること。影、砂埃、光、武器先端を足元基準に含めません。大きなエフェクトは別スプライトに分離します。

## 足場パーツを追加する

1. 衝突を持つ横長パーツは、コンパクトな正方形プロップ集へ混ぜず、単体または横長セルで生成する。
2. 上面の床レールを既存パーツと同じ高さ・太さ・水平形状で描く。
3. `assets/objects/platform_modular/module-spec.json` の `pieceDefinitions` に、元画像と幅規格を登録する。
4. `npm run assets:normalize` を実行する。
5. `npm run validate:contact` が通ることを確認する。
6. `normalized/assembly-contact-preview.png` で、緑の接触線が連続した床レールへ重なることを確認する。

床面の測定は、孤立したクランプや装飾突起を無視するため、画像中央76%の各列で最初に現れる不透明ピクセルの中央値を使います。

## ゲーム内確認

- `F2`: 接地デバッグ表示を切り替える。
- `?debug-contact`: 起動時から接地デバッグを有効にする。
- 緑: 足場の物理接触面。
- 赤: プレイヤーの物理ボックス。
- 黄: プレイヤーの足元。

地上では緑と黄のY座標が一致すること。通常表示でも靴底と床レールの間に背景色が見えないことをPC・縦スマホの両方で確認します。

## 組み込み禁止条件

- 自動検査が失敗する。
- フレーム間でキャラの大きさが10%以上変化する。
- 靴底や床レールが半透明エフェクトに隠れて測定できない。
- 床パーツの継ぎ目で接触線が1px以上ずれる。
- デバッグ線は一致するが、通常表示で背景色の隙間が見える。
