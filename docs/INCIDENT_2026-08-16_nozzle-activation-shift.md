# 結晶噴出口・起動時位置変化インシデント報告

- 発生日: 2026-08-16
- 対象: 結晶足場の噴出口描画
- 重要度: 中（操作対象の位置一貫性と視認性を損なう）
- 状態: 原因特定・修正・回帰検査追加

## 事象

結晶足場を起動すると、床へ接地していた噴出口が横方向へ移動または縮小したように見えた。ゲームデータ上の噴出口座標は変化していなかった。

## 直接原因

起動前後で同じ噴出口を描画していなかった。

- 待機中: `crystalNozzle1` を独立した噴出口オブジェクトとして描画
- 成長中・安定中: 独立した噴出口を非表示にし、結晶足場画像内に描き込まれた別の台座へ置換

結晶足場画像は足場長へ合わせて拡縮される。今回の4セグメント構成では、独立噴出口の見える台座幅が約150pxなのに対し、足場画像内の台座は約99px相当となった。

中心座標は同じでも左右端が約25pxずつ内側へ移動するため、プレイヤーには噴出口が移動したように見えた。起動状態によって別画像へ差し替える設計が根本原因である。

## 修正

噴出口オブジェクトを待機・成長・安定・劣化・崩壊の全状態で描画し続けるよう変更した。

- X座標: 常に噴出口オブジェクトの座標
- 接地Y座標: 常に共通の `floorAlignedDrawY`
- 表示サイズ: 常にオブジェクトの `w` / `h`
- 状態差: 同一アンカーのフレーム変更と発光だけで表現

結晶足場画像は先に描画され、その後に独立噴出口が前面へ描画される。足場画像内の小さい台座は、同じ中心に描かれる実物の噴出口で覆われるため二重には見えない。

## 再発防止策

1. 起動可能な装置本体は、状態変化で別オブジェクトへ置換しない。
2. 位置・寸法・接地アンカーは全状態で不変とし、発光や内部表示だけを変更する。
3. 結晶足場スプライト内の装置表現は背景側の補助表現として扱い、実物装置を非表示にする根拠にはしない。
4. `integratedIntoHorizontalPlatform` のような装置非表示分岐が復活した場合、`validate:growth` を失敗させる。
5. 全成長フェーズで `floorAlignedDrawY` を使う同一噴出口描画が存在することを自動検査する。
6. アセット生成時は、装置と生成物を可能な限り別レイヤー・別スプライトとして作成する。

## 完了条件

- 起動前後で噴出口の見える中心・幅・床接地線が変化しない
- 成長・劣化・崩壊中も噴出口本体が表示される
- 結晶の発生中心と噴出口中心が一致する
- `validate:growth` と全体検証が通る
- 実画面で待機状態と起動状態を比較確認する
