# 縦切り01：導入ランウェイ＋ジャンプ練習区画

対象範囲はワールドX座標 `0〜1550`。背景は既存パララックスを使い、床・取得物・敵・噴出口はすべて独立したランタイム要素として保持する。

## プレイの流れ

1. `x=150` から走り始め、`crystal-01` を約1秒以内に取得する。
2. `jump-lesson-a` へ最初のジャンプ。失敗しても下は連続床で、即死穴にはならない。
3. `x=850〜1080` で上下ルートを選ぶ。
4. 下ルートは `nyabi-clean-01` を踏むか避け、`vent-01` の周期を読む。
5. 上ルートは連続ジャンプの難度が少し高い代わりに、強調表示された `crystal-04` を取得し、敵と噴出口を迂回できる。

## 操作リズム

`run → jump → choose-route → stomp-or-evade → time-or-bypass`

同一操作を3回連続させない。縦切りのビートは `data/crystal-lab-objects.json` の `verticalSlice.beats` に保存し、`npm run validate:course` で検査する。

## 編集単位

- 基本ルート：`ground-a`, `ground-b`
- 最初のジャンプ：`jump-lesson-a`
- 上ルート：`jump-lesson-b`, `crystal-04`
- 敵：`data/crystal-lab-scene-hooks.json` の `nyabi-clean-01`
- ギミック：`vent-01`

「ここがつまらない」と指摘された場合は、まず該当ビートと上記IDだけを変更する。背景、接地基準、Prefab画像の拡大縮小・回転は変更しない。

## 合格条件

- 最初の報酬まで5秒以内
- 基本ルートの床がX=0〜1550で連続
- 上ルート報酬が存在
- ニャビクリーンが1体だけ存在し、巡回範囲が有効
- 周期噴出口がジャンプ練習区画内に存在
- 接地・敵・コース・ビルド検証がすべて成功
