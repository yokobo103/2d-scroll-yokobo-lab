## 1. 現状の実測

`assets/sprites/bosses/nyabi_drone_core/parts_v1/runtime/` を計測し、ピボットを中心に実際に回してレンダリングした結果。

### (a) アンカーが実際の球からずれている

| | 値 |
|---|---|
| `anchors.elbowRight`（現行の回転中心） | (1128, 544) |
| **実測した第1関節の球の中心** | **(1138, 536)**、半径 43 |

10px 外・8px 下にずれている。

### (b) 前腕の切り出しに肩アーマーの黒い部分が混入している

静止時は重なって見えないが、回すと振り回されて黒い破片として出る。±30°で既に見える。

### (c) 本体側に受け口（ソケット）が無い

**これが本質。**肩は平らな板で終わっており、球はその横に接しているだけ。腕を振ると球が肩板から離れ、**浮いた球**に見える。4倍拡大で、肩板と球のあいだに背景が見えることを確認済み。

### (d) 回転中心の位置が低い

胴体の中心（y≈496）より 48px 下。肩から生えているというより、腕の中ほどで折れて見える。

### 後処理では直らない

初版で「ピボットに円を敷く」、二版で「球の円で切り落とす」と書いたが、**どちらも誤り**。

- (b) は切り方で直るが、(c) は**絵に情報が無い**ので切り方では作れない
- 実際に半径32でクリップして検証したところ、破片は消えたが「浮いた球」は残った。さらにクリップ円が実際の球（中心(1138,536)・半径43）を貫いており、輪郭線のない切り口が露出した

## 2. 素材の要件 — 球関節を絵として描かせる

`$generate2dsprite` で作り直す。パラメータは前回同様（`asset_type: creature` / `view: side` / `bundle: single_asset` / `reference: attached_image` / `art_style: project-native`）。

**追加する要件は肩の構造。これが今回の主眼。**

1. **肩に円いソケット（受け口）を描く。**球がはまり込む窪みと、その縁（リム）。**本体側に残るので、腕を何度振っても関節として読める**
2. **球は完全な真円で、全体が見えている。**装甲や肩板に隠れないこと。隠れていると切り出せない
3. **ソケットの中心と球の中心を一致させる。**そこが回転中心になる
4. **球はソケットより一回り小さい。**回してもソケットの縁からはみ出さないサイズ
5. **関節の位置を、現状より上げる。**胴体の中心（またはやや上）に置く。所長の指摘。**絵で決まるので後から動かせない**

前回の3つの守るべき点は引き続き有効。

- アニメーションシートにしない。1枚だけ出す（`split_grid` はセルごとに個別クロップ＋リスケールするため、部位を別セルに置くと相対位置と縮尺が失われる）
- `cell_size` に 128 を使わない。出力の短辺で最低768px
- 正方形セルに押し込まない（腕が横に張り出すので本体が縮む）

---

## 3. 切り出しとアンカー

| 部品 | 内容 |
|---|---|
| `body` | ソケットを含む本体。**ソケットは本体側に残す** |
| `forearm` | 球より外側の腕全体＋砲口。**切断は球の輪郭ちょうど**。左は反転して使う |

- **回転中心＝球の中心。**アンカーは実測して記録する。**目分量で置かない**（現行は10px ずれていた）
- `anchors` に `elbowLeft` / `elbowRight` / `muzzleFromElbow`(dx,dy) / `forearmAngleLimit` / `ballRadius` を記録し、コードにハードコードしない

### 任意 — 2段関節にすると更に自然になる

現状の絵は関節が3つあるのに、**一番内側の1つだけでチェーン全体を剛体として回している**ので、腕が1本の棒として振れる。厚みの実測では第2関節が (1276, 568)・安全半径53 にある。

肩と第2関節の2段に分け、それぞれ半分ずつ回せば、同じ照準角でも1関節あたりの曲がりが半分になり、腕として読める。**今回の作り直しでは必須にしない**が、素材を作る段階で第2関節も真円で描かせておくと、後から足せる。

## 4. 検収条件

- **前腕を ±60° まで振っても、肩が関節として読める。**球がソケットから外れて浮いて見えないこと
- 黒い破片が出ない
- 球の切り口に、輪郭線のない直線や弧が露出していない
- 回転中心が実測値で、`anchors` から読まれている
- `npm run validate` と `npm run build` が通る

## 5. 確認のしかた

**目視の1枚では見落とす。**継ぎ目は特定の角度でだけ出る。

前腕角度を **-60 / -30 / 0 / +30 / +60** に固定して5枚レンダリングし、**関節部を4倍に拡大して**並べること。今回の「浮いた球」も、等倍では見えず4倍で初めて分かった。

`tools/render_boss_joint_check.py` として残し、素材を差し替えるたびに同じ検査ができるようにする。
